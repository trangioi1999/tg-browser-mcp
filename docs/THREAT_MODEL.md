# Threat model (STRIDE-oriented)

Assets: user's local files and credentials, internal network services, application sessions/tokens, cloud credentials (metadata), the integrity of actions performed on business systems.

| #   | Threat                                        | Vector                                                                                | Mitigation                                                                                   | Test                                                                  |
| --- | --------------------------------------------- | ------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------- | --------------------------------------------------------------------- |
| T1  | SSRF to cloud metadata                        | page/agent navigates or fetches 169.254.169.254, IPv4-mapped IPv6, metadata hostnames | unconditional metadata block in DomainPolicy; route + redirect + WS enforcement              | `domain-policy.test.ts`, `security.test.ts`                           |
| T2  | SSRF to internal network                      | private IP literals, internal hostnames                                               | `allowPrivateNetwork=false`, allowlist, DNS check                                            | same                                                                  |
| T3  | Redirect-based bypass                         | allowed URL 302 → internal                                                            | `request` event redirect check, navigation cancel, final URL check                           | `blocks redirects…`                                                   |
| T4  | DNS rebinding                                 | attacker domain resolving to private IP                                               | resolve + check non-allowlisted hosts                                                        | `detects DNS rebinding…`                                              |
| T5  | Popup / new tab bypass                        | `window.open`, `target=_blank`                                                        | context-level routes; popups' first request handled                                          | `…popups and sub-requests…`                                           |
| T6  | Prompt injection                              | page text instructs the agent                                                         | server instructions; data rendered as quoted text; policy gates independent of model         | `treats prompt-injection text as data`                                |
| T7  | Arbitrary file read (exfiltration via upload) | `browser_upload_file /etc/passwd`                                                     | allowed roots + realpath + approval                                                          | `restricts file paths…`, `permission manager`                         |
| T8  | Arbitrary file write / path traversal         | screenshot/trace/report `path`, session/project names                                 | allowed roots; safe-name regex for names                                                     | `blocks path traversal…`, `rejects traversal in names`                |
| T9  | Credential leakage to the model               | snapshots, attributes, network headers, errors, logs                                  | masking + redaction + normalized errors; session state counts only                           | `redacts sensitive field values…`, `redactor.test.ts`, stdio log test |
| T10 | Cross-session data leakage                    | maker cookies visible to checker                                                      | one BrowserContext per session; one harness per HTTP MCP session                             | `isolates sessions…`                                                  |
| T11 | Session hijacking from disk                   | stolen state file                                                                     | AES-256-GCM, 0600 key file / env key, expiration                                             | `session store`                                                       |
| T12 | Unauthorized remote control                   | exposed HTTP transport or CDP                                                         | HTTP off by default, token, loopback bind, Host/Origin checks, rate limit; CDP loopback only | `http-transport.test.ts`, lifecycle CDP test                          |
| T13 | Weakening the browser                         | `--disable-web-security`, `--ignore-certificate-errors`, TLS verify false             | denied launch args, schema rejects verify=false                                              | `config`, `permission manager`                                        |
| T14 | Destructive business actions                  | agent clicks "Delete"/"Transfer"                                                      | destructive-name approval; non-idempotent steps never auto-retried                           | `requires approval…`, `does not retry non-idempotent…`                |
| T15 | Resource exhaustion                           | many sessions/tabs, huge pages, long waits                                            | maxSessions, maxPagesPerSession, node limit, char budgets, tool timeouts, ring buffers       | `limits resources`, pagination test                                   |
| T16 | Code execution                                | eval/shell tools                                                                      | none exposed; workflow conditions use a non-eval mini language                               | `evaluates the safe condition language`                               |
| T17 | Log/stdout protocol corruption                | logging to stdout in STDIO mode                                                       | pino on fd 2; ESLint `no-console`                                                            | `keeps stdout clean`                                                  |

Residual risks are listed in [SECURITY.md](SECURITY.md#limitations-honest).
